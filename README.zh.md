# dsh-evolution

面向 DeepSeek Harness 的记忆与技能管理插件。

## 功能定位

dsh-evolution 用于跨会话保存项目事实，并把可复用的任务流程整理为技能。插件提供记忆写入、技能生成与维护、任务复盘、技能库整理、技能合并、写入审批、版本撤销和诊断等能力。

它适用于需要长期维护项目约定、操作偏好和专用工作流程的 Harness 用户。插件不训练模型，也不提供托管模型服务；需要模型判断的功能使用 DSH 已配置的模型提供方。

## 记忆与技能

- **记忆**保存项目事实和用户偏好，例如构建命令、目录约束和发布要求。项目记忆与用户画像分别有字符预算，并在预算内注入后续会话。
- **技能**保存一类任务的操作方法，由 `SKILL.md` 正文及可选的脚本、模板和参考资料组成。模型按名称和简介发现技能，在需要时加载并执行。

记忆回答“有哪些事实需要保留”，技能回答“这类任务应当怎样完成”。MCP 负责连接工具和资源，技能负责组织这些工具的使用步骤与完成标准，二者不属于同一层。

## 安装

环境要求、四种安装形态和升级步骤见 [INSTALL.md](INSTALL.md)。默认安装完整形态：

```bash
dsh plugin --profile web add @lmzhen/dsh-evolution-all
# 重启 DSH，然后在会话中执行：
/evolution doctor
```

桌面 GUI 将 `--profile web` 改为 `--profile desktop`。安装后可让 Agent 记住一条项目事实，再开新会话确认记忆已注入；`doctor` 用于检查安装形态和服务状态，不能替代实际读写验证。

完整源码布局的安装结果为 35 个包；发布清单共 36 个包，agent preset 单独计算。

## 主要功能

| 功能 | 当前行为与默认条件 |
|---|---|
| 记忆 | `all`、`preset` 及分层预设的选定会话提供。项目记忆和用户画像预算分别为 2200、1375 字符；达到上限后拒绝新增，不静默截断 |
| 技能写入与版本 | Agent 可创建、修补、拆分和归档技能；可查看历史、撤销正文改动或从归档恢复 |
| 技能目录与检索 | 默认发布完整技能目录，并通过原生 `skill` 工具加载；`skill_search` 提供本地检索，域卡和目录裁剪默认关闭 |
| 任务复盘 | 默认开启，按 10 次加权工具调用的间隔，在满足任务信号条件后的完成边界触发；使用当前会话模型，可新建技能或按提示修补本次使用的技能 |
| 技能库整理 | 默认按时间间隔和空闲条件执行确定性整理，标记过时技能并归档；LLM 合并提名需单独启用 |
| 技能合并 | 通过 `/evolution merge scan` 或 `pair` 发起。scan 需要本地 potion 模型，缺少 LLM 时可回退 stub；普通 pair 不需要 potion，但 round1/authoring 需要子会话模型。发起后默认自动批准，`mergeApproval` 可改为人工批准 |
| 写入审批 | 默认关闭；开启后可暂存普通记忆和技能写入。整理器写入与 merge 提交不使用这套审批 |
| 诊断与界面 | 提供 `/evolution doctor`、整理报告、技能健康和知识图；`all` 在 Web/桌面 GUI 提供设置页、技能历史和合并面板，健康面板默认关闭 |

各项功能的触发条件、失败行为和限制见 [功能说明](docs/features.md)。

## 安装形态

| 形态 | 适用场景 | 能力与界面 |
|---|---|---|
| `all` | 默认完整使用 | 所有会话提供记忆和技能工具；Web/桌面 GUI 提供设置页与面板 |
| `host` | 不授予模型记忆/技能写入工具 | 保留显式合并、后台整理、手动维护和诊断；自动复盘与用量统计不生效，无设置页和侧栏面板 |
| `preset` | 旧配置迁移 | 工具范围接近 `all`，但无设置页和侧栏面板 |
| 分层预设 | 仅在选定会话提供工具 | `host` 加 Evolution 预设；其他会话不启用插件的自动行为，无设置页和侧栏面板 |

同一 profile 只能使用一种形态。精确的会话影响见 [packages/INSTALL.md](packages/INSTALL.md)，安装命令见 [INSTALL.md](INSTALL.md)。

## 常用命令

| 命令 | 用途 |
|---|---|
| `/evolution doctor` | 检查安装形态、版本和服务状态 |
| `/evolution pending` | 查看等待审批的普通写入 |
| `/evolution skill history <name>` | 查看技能正文和支撑文件的历史 |
| `/evolution skill undo <name>` | 回退技能正文；不恢复支撑文件 |
| `/evolution curator status` | 查看自动整理状态 |
| `/evolution merge status <runId>` | 查看已发起的合并运行 |
| `/graph` | 浏览或编辑技能与记忆图 |

完整命令说明见 [docs/commands.md](docs/commands.md)，常用配置见 [docs/configuration.md](docs/configuration.md)。

## 数据与安全

- 默认装配的插件数据保存在 `$DSH_HOME`，不依赖家族托管服务。备份与恢复范围见 [运维指南](docs/operations.md)。
- 受控的记忆/技能模型写工具会扫描调用参数，相应写路径执行结构检查和策略保护；审批是可选的附加控制，不替代这些检查，也不覆盖整理器和 merge 的内部写入。
- 技能删除采用归档。正文历史记录失败不会阻断原写入，因此撤销前应确认可用版本；支撑文件不随正文撤销回退。整理前快照可恢复，合并保留运行记录和撤销依据。
- 本地保存不等于内容不外发：复盘、LLM 整理和 discovery 域生成会把相应任务或技能内容发送给所配置的模型提供方；branch 复盘还会向子会话复制会话事件。
- API key 由 DSH 的模型与凭据配置管理，不应写入技能、记忆或插件配置。详见 [模型与 API key](docs/api-keys.md)。
