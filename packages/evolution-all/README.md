# @lmzhen/dsh-evolution-all

`DEFAULT install` is the full installation bundle. It mounts the host automation and the profile-root memory/skill model rows so every session receives the family model tools and prompt guidance without selecting a separate preset.

The full form also includes the unified skill-history workbench page (history / pending / merge / health views), while editable parameters live on the platform plugin-config cards. The health view ships but is disabled by default.

Use this form for the normal full installation. To shrink the installation, uninstall it before installing `host`, the one-click `preset`, or the layered `host + Evolution preset` form; these forms are mutually exclusive because their shared rows must not mount twice.

Ordinary memory/skill approval is disabled by default. Merge has its own approval and platform-write controls.
