# Anchored Standard compatibility fixture

Vendored from https://github.com/xiaobright/dsh-anchored-standard (MIT).

These two files are the actual bootstrap/compaction plugins from the
`preset/` mode. They are used by `tool-memory/tests/anchored-compat.spec.ts`
to verify that dsh-evolution tools follow the anchored tool-catalog contract
without depending on the network at test time.
