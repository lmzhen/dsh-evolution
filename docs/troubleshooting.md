# 排障：先定位，再改配置

先看安装形态，再看功能有没有装上，然后看命令/工具，最后才看数据和权限。不要一上来改代码。

## 1. 命令/工具不存在

| 症状 | 先查 | 处理 |
|---|---|---|
| 输入 `/evolution` 没反应 | 安装形态 | 先跑 `/evolution doctor`；重装或换形态 |
| 没有 `memory` / `skill_manage` | 装的是 host | 换 `all` 或分层预设 |
| 只有部分会话有工具 | 分层预设 | 新建会话时选 Evolution 预设 |

## 2. 审批里没东西

审批默认关闭。没打开时，写入直接执行，`pending` 当然是空的。

开了审批还是看不到，先确认审批功能有没有装上。待批有保留时间，过期会按拒绝处理。`release` 只回收执行中的孤儿，不是批准。

## 3. 复盘/整理不跑

复盘按阈值触发，不是每句话都跑；看 `/evolution params --group review`。

host 形态一定不触发自动复盘，因为它没有记忆/技能工具。要看复盘就用 all。

整理有间隔和空闲条件；`/evolution curator status` 会告诉你是不是跳过了。没有模型时，依赖模型的整理/复盘部分不会跑，只做确定性部分。

## 4. 合并失败

| 提示 | 处理 |
|---|---|
| 模型未配置 | 配置本地合并模型目录；不会自动下载 |
| 合并未就绪 | 先看 `/evolution doctor` 的安装形态/服务状态，再用 `/evolution merge doctor` 看合并配置 |
| 运行被占用 | 等当前 run 结束，或取消后重试 |
| 没有会话/Agent | 在真实会话里跑，不要在没有 Agent 的上下文里跑 |

## 5. 面板/设置卡片不出现

设置区段只在 all + Web/桌面 GUI 出现。TUI、headless、host、preset 都没有。

历史面板需要连接服务；没有连接时读不到数据。

只有 all 带合并面板；host/preset 没有。健康面板默认关闭，要显式启用。

## 6. 数据坏了/丢了

先备份 `$DSH_HOME`，不要手改 JSON。

状态文件损坏会被隔离保留，不会当空覆盖。存储冲突时命令会直接报错；按 doctor 提示处理。

技能删除是归档，先用 `/evolution skill restore` 找；整树回退用 `/evolution restore`。

## 7. 版本/平台线

当前验证线是 DSH `0.2.1-rc.3`，最低 `0.2.1-rc.2`；旧线不跨线。

升级顺序是先平台、后家族，反过来会坏。`/evolution doctor` 的家族版本要和安装包一致；不一致说明混装，重装。

## 8. 收集证据

```text
/evolution doctor
/evolution curator report
```

再加上启动日志。Web home 一般在 `$DSH_HOME/logs/`；桌面 home 没有这个目录时，用桌面应用的日志入口。只发“没反应”很难查。
