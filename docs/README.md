## 一句话版本

dsh-evolution 给 DeepSeek Harness 加一层“会记忆、会改技能、可审批、可回滚”的自进化能力。模型只能写记忆和技能；策略、提示词、路由、状态和审计历史属于控制面，模型改不了。

## 重要边界

- 它不是一个模型，也不是托管服务；没有自己的服务器，没有遥测。
- 它不做“跨进程文件锁”；状态介质的诚实话语是 **single-process**。
- 它不会自动把 shadow/影子写入晋升成正式写入。
- 默认安装是全量 `all`；`host` 是只装自动化、不给模型工具；两者不能同挂。
- 当前文档对应家族 **0.32.4**，验证平台线 **DSH 0.2.1-rc.3**（最低 0.2.1-rc.2）。平台线只支持这一条，旧线不跨线兼容。
