# 这个插件到底会做什么

不用记包名。你只会感知到五类能力：记忆、skill 写入、skill 检索、复盘/整理/合并、审批与回退。它们不是一条流水线：触发条件不同，完成度也不同。

## 1. 记忆：它记得你讲过的事

**你会看到**：新会话开头，Agent 已经知道项目的构建命令、目录约定、你的偏好。

**怎么发生**：你对它说“记住……”，或它自己判断某条事实值得留下。它写入 `$DSH_HOME/memories/MEMORY.md`（项目）和 `USER.md`（你），下次会话自动带一段快照。

**默认**：开启。预算默认 2200 / 1375 字符；写满会拒绝并告诉你，不会悄悄截断。

## 2. 技能：它把自己的做法存下来

**你会看到**：Agent 把“发布前要跑哪些检查”“这个项目的调试步骤”写成技能；以后遇到同类任务会直接照着做。

**怎么发生**：它通过 `skill_manage` 创建、修补、拆分、归档技能；技能进入技能目录，模型以后可以按名称和简介发现它。改坏了用 `/evolution skill history <name>` 看版本，`/evolution skill undo <name>` 退回。

**默认**：开启。写入有保护；删除是归档，不是硬删。

**技能多了以后**：默认把可见技能目录整体发布；当数量增长到全量目录不再合适时，`skill_search` 提供检索，discovery 的域卡/裁剪提供另一种组织方式。后者默认关闭、依赖模型/投影条件，是条件能力，不是“每次任务都保证选对技能”。

**使用之后**：复盘会看本次会话真正加载或用过哪些技能。如果某个技能缺步、过时，或者和你的偏好不符，它会优先给这个技能打补丁，而不是新建一个。更新发生在任务收尾/阈值触发时，不是任务进行中直接改文件。

## 3. 复盘：它偶尔回头看

**你会看到**：在自然节点，Agent 回顾刚才的对话，给出“下次应该怎么改”的建议；如果本次加载的技能有问题，它会优先补丁那个技能，而不是只写一条建议。不是每句话都打断你。

**默认**：开启。累计约 10 次工具调用后，在任务收尾时触发；模型会多跑一轮，所以你会看到一条自我复查消息。想调频率或关掉，见 [设置](configuration.md)。

## 4. 整理：它清理自己的技能库

**你会看到**：长期不用的技能被标 stale / 归档，近重复的被合并；报告里会写做了什么。

**默认**：宿主启动约 10 秒后判断一次，之后每小时查一次；距上次整理满 168 小时且你空闲约 2 小时才跑。整理完**不会发消息**，技能可能直接从列表消失；用 `/evolution curator status` / `report` 追。可以先暂停。

## 5. 合并：重叠技能合成一个

**你会看到**：两个技能高度相似时，系统给出合并提议。默认会自动合并并写入；打开审批才会停在你这里。合并后可撤销。

**怎么发生**：系统在后台筛选并准备合并；默认 `mergeApproval=false`，直接合并并写入；打开审批才会等你批准或拒绝。合并是独立流程，不走普通写入审批；面板只读，展示队列并复制命令；入口是 `/evolution merge …`。

## 刹车：在语义自动化和用户注意力之间取得平衡

设计目标：低风险动作自动、关键写入人工确认，把有限注意力留给真正需要决定的时刻。

当前实现：**审批默认关闭**，只覆盖可暂存的 memory/skill 写入；curator 的归档/合并和 merge 的提交**不经过**审批；待批主要在有设置页的形态里看得到，通知/收件箱还不完整。

- **删除是归档**；恢复用 `/evolution skill restore`。
- **技能有版本**；单技能撤销、整树恢复都是显式操作。
- **合并有记录**；撤销按这次合并执行。

## 默认关闭或需要条件的功能

| 能力 | 默认 | 什么时候需要管 |
|---|---|---|
| 审批 | 关闭 | 不放心自动写时打开 |
| 技能健康面板 | 完整体验里默认关闭 | 需要改安装配置；普通用户可以不碰 |
| 合并 | 需本地合并模型；默认自动接受 | 想每次人工审批时打开 `mergeApproval` |
| 模型/API key | 自动复盘/LLM 整理/域生成需要 | 见 [API key 与模型](api-keys.md) |

## 界面里有什么

**设置里的「自进化」**（只有 `all` + Web/桌面 GUI 有）：

- **待批写入**：审批开启时，这里是批准/拒绝的入口；能看到种类、摘要、来源和“执行中”警示。
- **诊断**：与 `/evolution doctor` 同一份检查结果，点刷新即可。
- **参数卡**：记忆、复盘、整理、合并等常用项。

**左侧栏**：

- **技能历史**：版本、差异、正文、撤销。
- **技能合并**：待判断/待批准/待合并/无需合并四个队列，只读；动作按钮复制命令。
- **技能健康**：结构体检；完整安装里默认关闭。

这些面板只在 Web 客户端出现；host/preset/分层都不带。

## 它不做什么

- 不训练模型，不把对话上传到托管服务。
- 不保证 host 形态有完整工具；host 是缩配。
- 不替你做策略/审批决定；它只把选择摆在你面前。
- 不保证模型每次都能选对技能；描述、触发条件、任务本身都会影响选择。
- 不自动修复健康/漂移问题；它只报告，修复仍需写入或整理动作。
